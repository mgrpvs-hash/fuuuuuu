# Monopoly TWA (Telegram Web App)

## Установка и запуск

1. Клонировать репозиторий
2. Установить зависимости: `npm install`
3. Перейти в `apps/server`, выполнить:
   - `npx prisma migrate dev --name init`
   - `npx prisma generate`
4. Запустить сервер: `npm run dev` (порт 3001)
5. В другом терминале запустить клиент: `npm run dev` (из `apps/client`)
6. Открыть `http://localhost:5173`

## Тестирование с двумя игроками

- Откройте две вкладки браузера в режиме инкогнито (или два разных браузера).
- В каждой вкладке будет создан гость (Guest).
- Первый игрок создаёт комнату.
- Второй игрок заходит по коду комнаты из списка.
- Хост нажимает «Начать игру».
- Игра начинается.

## Подключение к Telegram

1. Запустите сервер и клиент.
2. Используйте ngrok: `ngrok http 5173` (для клиента) и `ngrok http 3001` (для сервера, если требуется).
3. Создайте бота через @BotFather, установите webhook или используйте Mini App через Bot API.
4. Вставьте ссылку на ngrok в настройки Mini App.

## Технологии

- React, TypeScript, Tailwind, Socket.IO
- Node.js, Express, Prisma, SQLite
